# ZXing Core 3.5.4

`zxing-core-3.5.4.jar` is the Apache-2.0 licensed ZXing Core release from Maven Central (`com.google.zxing:core:3.5.4`). It generates the invoice-number QR code on A4 invoice PDFs. The QR encodes the invoice number; it is not an IRP-signed e-invoice QR.
